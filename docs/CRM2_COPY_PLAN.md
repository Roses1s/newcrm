## 1. Что такое `/crm2` в проекте сейчас

клиентская: **ни одного запроса к серверу**, все данные вымышленные и живут в

Маршруты (из `frontend/src/app/router.tsx`):

```
/crm2                → LeadBoard (доска)
/crm2/leads/:id      → LeadPage  (карточка лида)
/crm2/customers      → Клиенты
/crm2/tasks          → Задачи
/crm2/analytics      → Аналитика
/crm2/settings       → Настройки
/crm2/deals          → заглушка «Сделки»
/crm2/calendar       → заглушка «Календарь»
```

Внутри `crm2` стоит `RequireAuth` (сессия через `/api/v1/auth/refresh`), то есть
сейчас раздел открывается только после входа в основную CRM.

## 2. Ключевой вывод: `/crm2` уже изолирован

Проверил все импорты `crm2`-файлов — они используют **только**:

* `react`, `react-dom`, `react-router-dom`, `lucide-react`;
* файлы внутри самой папки `crm2/`;
* тесты: `vitest`, `@testing-library/*`.

Ни одного импорта из `@/shared/*`, `@/app/*`, `@/features/crm/*` — то есть
**никаких зависимостей от остального проекта нет**. Единственные внешние
привязки:

1. `RequireAuth` (обёртка в роутере) — требует бэкенд авторизации;
2. `index.css` (`@import "tailwindcss"` + токены `odoo-*`) — `crm2` пользуется
   только стандартными утилитами Tailwind (проверено: классов `odoo-*` в
   `crm2` нет, кроме одного упоминания в тексте комментария);
3. `public/logo.svg` и `public/theme.js` из шапки `index.html`;
4. тема шрифта/базовых стилей из `@layer base` (`body { font-size: 13px }`).

Значит точная копия — это перенос папки + минимальный хост-каркас
(Vite + Tailwind v4 + роутер), без бэкенда. Визуал, поведение, доступность
(`aria-*`), анимации и тексты сохраняются **байт в байт**.

## 3. Структура новой копии (вариант «отдельный проект»)

```
crm2-standalone/
├── index.html                  # lang=ru, title «CRM Детроид», фавикон logo.svg
├── package.json                # react 19, react-router-dom 7, lucide-react, vite 6, tailwind 4
├── tsconfig.json               # strict, paths "@/*" → src/*
├── vite.config.ts              # host 0.0.0.0, allowedHosts: true, alias @, vitest jsdom
├── eslint.config.js / .prettierrc.json   # те же правила, что в оригинале
├── public/logo.svg, theme.js
└── src/
    ├── index.css               # tailwind + @layer base (шрифт, размеры, поля ввода)
    ├── main.tsx                # createRoot + ErrorBoundary-заглушка
    ├── app/router.tsx          # только маршруты /crm2/* (+ редирект / → /crm2)
    └── features/crm2/          # ← точная копия 17 файлов исходников
        └── *.test.tsx          # ← точная копия 6 файлов тестов
```

Отличия от оригинала — **только три**, и все вынужденные:
1. нет `RequireAuth` → `/crm2` открывается сразу (демо без логина);
2. `/` редиректит на `/crm2` (в оригинале `/` — лаунчер основной CRM);
3. не переносятся страницы основной CRM (лаунчер, заявки, бухгалтерия, админка, `/crm`).

## 5. Что будет проверено как «точная копия»

* все 8 маршрутов рендерятся с тем же текстом, что в оригинале;
* светлая/тёмная тема, ключ `crm2.theme`, состояние тумблера — те же;
* сворачивание панели и ключ `crm2.sidebar.collapsed` — те же;
* drag&drop карточек и колонок, вставка «перед карточкой», меню действий;
* переименование/цвет/удаление этапа с переносом карточек;
* автосохранение 3 с, проверка ИНН по контрольной сумме, блокировка ухода;
* чаттер: заметки, история, вложения (лимит 25 МБ), проигрыш с причиной, передача;
* таблица клиентов, фильтры и поиск; задачи и «Выполнить»; аналитика; настройки;
* 46 тестов из оригинала проходят без правок.
